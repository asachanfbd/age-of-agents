# WhatsApp Notification Script (`notify.sh`)

This script sends a WhatsApp message using a custom API endpoint. 

## Usage

You can call the script from the terminal, passing the message you want to send as the first argument. If the message contains spaces, make sure to wrap it in quotes.

```bash
# Make the script executable (only needed once)
chmod +x docs/notify.sh

# Run the script
./docs/notify.sh "Hello! This is a test message."
```
